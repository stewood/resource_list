# Debug and Development Files Archive

This directory contains archived debug and development files that were used during the development and testing of various verification approaches.

## Archived Components

### Debug Files
- `cursor_agent_output.txt` - Cursor agent output log
- `debug_cursor_context.py` - Cursor context debugging script
- `debug_comparison.py` - Comparison debugging script
- `debug_json_extraction.py` - JSON extraction debugging script

### Development Files
- `demo_json_formatters.py` - JSON formatter demos
- `json_formatter.py` - JSON formatter utility
- `rich_example.py` - Rich text example
- `rich_json_demo.py` - Rich JSON demo
- `simple_rich_demo.py` - Simple rich demo
- `test_prompt.txt` - Test prompt file

## Archive Date
January 15, 2025

## Reason for Archive
These files were used during development and testing of various verification approaches. They are no longer needed as the MCP Server approach has been chosen as the preferred verification method.

## Current Verification Method
MCP Server located at `mcp_server/` directory.
